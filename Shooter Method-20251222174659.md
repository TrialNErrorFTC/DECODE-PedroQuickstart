[https://medium.com/@vikramaditya.nishant/programming-a-decode-shooter-4ab114dac01f](https://medium.com/@vikramaditya.nishant/programming-a-decode-shooter-4ab114dac01f)

if hooded ("kinda"):
1. Update localization (e.g. query pinpoint, re-localize with AprilTags)
    1. calculate distance from apriltags [https://docs.limelightvision.io/docs/docs-limelight/tutorials/tutorial-estimating-distance](https://docs.limelightvision.io/docs/docs-limelight/tutorials/tutorial-estimating-distance)
2. Calculate the hood angle using the InterpLUT/regression, and move the servo to this position
    1. just setup a LUT and use math
3. Spin the flywheel using the velocity controller
    1. tune this
4. Aim the turret/drivetrain using PID ← maybe for auto
    1. use the visual servoing thingy or js use pedropathing
5. If the robot is aimed (e.g. turret/drivetrain error is <5deg) and the flywheel is at an appropriate speed (e.g. <50rpm of error), feed the ball into the shooter!

if not hooded:
1. Update localization (e.g. query pinpoint, re-localize with AprilTags)
2. Calculate the necessary velocity using the v0 equation
3. Calculate the flywheel speed needed with the regression
4. Spin the flywheel using the velocity controller
5. Aim the turret or drivetrain with a heading controller
6. If the robot is aimed (e.g. error is <5deg) and the flywheel is spinning at the right speed (e.g. <50rpm of error), then feed a ball into the shooting mechanism and score!
